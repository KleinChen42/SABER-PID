# Data and code availability

The public repository contains a locally validated reproducibility archive with answer-isolated public manifests, scorer-only references, immutable raw generation JSONL, deterministic analyses and figure scripts, tests, environment records, and SHA-256 manifests. The complete 54-cell native-budget matrix, qualified-budget quality experiment, closest-safe InternVL comparison, cost-sensitive decision grid, and DEXPI external-family branch are retained even when summarized in the main text. PIDQA/Dataset-PID source data are covered by the vendored CC0 record. The DEXPI branch freezes the official repository commit, vendored CC BY 4.0 license, source-image and XML hashes, deterministic selection and derangement rules, and logical-test-case grouping. Full upstream image collections are acquired by reference, and model weights are not redistributed. Original SABER-PID project code is released under the MIT License; third-party data and assets remain under their stated licenses.

Public repository and versioned release: https://github.com/KleinChen42/SABER-PID

An archival DOI can be added to the journal metadata and accepted manuscript after it is minted from the public release.
